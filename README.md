# ⏳ Feliz Cumpleaños Abuela Kata • Un Viaje en el Tiempo

Una experiencia web interactiva, moderna y emocionalmente diseñada para homenajear a la **Abuela Kata** en su cumpleaños, recorriendo las estaciones de su vida, sus frases célebres, pilares y recuerdos familiares.

---

## 🌟 Características Principales

- **Diseño Liquid-Glass Editorial**: Estética de cristal esmerilado con reflejos cálidos ámbar/oro y modo oscuro cósmico profundo.
- **Optimización Total para Móviles**: Diseñado *mobile-first*, adaptado para navegación táctil fluida en cualquier smartphone.
- **100% Editable**:
  - **Textos y Anécdotas**: Archivo central `src/data/abuelaData.ts` o edición en vivo mediante el botón flotante "Editar" con guardado automático en `localStorage`.
  - **Fototeca y Galería**: Visor interactivo con opción de subir nuevas fotos directamente desde la cámara o galería del celular.
  - **Música de Época**: Reproductor de audio flotante con temas musicales y soporte para añadir canciones en MP3 o enlaces de Spotify.
  - **Sala de Cine**: Pantalla cinematográfica retro compatible con videos locales (MP4), YouTube y Google Drive.
  - **Gran Celebración**: Lluvia de confeti interactivo en pantalla completa con `canvas-confetti`.

---

## 🚀 Instalación y Despliegue Local

1. **Instalar dependencias**:
   ```bash
   npm install
   ```

2. **Ejecutar en modo de desarrollo**:
   ```bash
   npm run dev
   ```

3. **Construir para producción**:
   ```bash
   npm run build
   ```
